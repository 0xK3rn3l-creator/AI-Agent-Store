# 📦 Warehouse CRM & AI Agent System

Інтелектуальна система управління складом (CRM), яка складається з FastAPI бекенду та AI-агента на базі Google Gemini SDK з підтримкою Function Calling. Агент може автоматично створювати постачальників, додавати товари, формувати замовлення та перевіряти підсумки за допомогою звичайних текстових команд.

---

## 📂 Структура проєкту

```text
proect/
│
├── api/                  # FastAPI бекенд
│   ├── models/           # SQLAlchemy моделі бази даних та підключення
│   └── routes/           # Ендпоінти (auth, products, suppliers, orders)
│
├── agent/                # Логіка AI-агента
│   ├── tools/            # Інструменти (API клієнти для взаємодії з бекендом)
│   ├── guardrails.py     # Обмеження кроків агента
│   ├── tracing.py        # Логування кроків
│   └── main.py           # Головний скрипт запуску агента (тести + інтерактивний чат)
│
├── ai-venv/              # Віртуальне середовище Python
└── README.md

```

---

## 🛠 Вимоги та встановлення

1. **Перейдіть у папки проєкту:**
```bash
cd ~/proect

```


2. **Активуйте віртуальне середовище:**
```bash
source ai-venv/bin/activate

```


3. **Встановіть залежності** (якщо вони ще не встановлені):
```bash
 pip install -r requirements.txt
```

## 🚀 Як підіймати та запускати проєкт

Для повноцінної роботи системи вам знадобиться **два окремі вікна термінала**: в одному працюватиме бекенд-сервер, а в іншому — AI-агент.

### Крок 1. Запуск FastAPI Сервера

У **першому терміналі**:

1. Активуйте віртуальне середовище:
```bash
source ai-venv/bin/activate

```


2. Запустіть FastAPI сервер через Uvicorn за допомогою `PYTHONPATH`:
```bash
PYTHONPATH=. python -m api.app

```



> Сервер запуститься на `http://0.0.0.0:8000`. При запуску автоматично перевіряється/створюється адміністративний акаунт (за замовчуванням: `admin` / `admin`).

### Крок 2. Налаштування API-ключа для OpenAI або длф Gemini, рекомендований перший варіант

Перед запуском агента переконайтеся, що у вашій системі встановлено змінну середовища з вашим ключем доступу до Google Gemini API:

```bash
export OPENAI_API_KEY="sk-....."
export GEMINI_API_KEY="ваш_реальний_ключ_тут"

```


### Крок 3. Запуск AI-Агента

Відкрийте **друге вікно термінала**, виконайте такі кроки:

1. Перейдіть до папки проєкту та активуйте середовище:
```bash
cd ~/proect
source ai-venv/bin/activate

```


2. Запустіть скрипт агента:
```bash
PYTHONPATH=. python -m agent.main

```



Під час запуску скрипт запропонує:

* **Виконати стандартне тестове завдання** (натисніть `y` або просто `Enter`): агент автоматично зареєструє тестового постачальника, додасть продукт, сформує замовлення та виведе підсумок.
* **Перейти в інтерактивний режим чату**: після завершення тесту (або якщо пропустити його) відкриється консольний чат (`Ти:`), де ви зможете вільно спілкуватися з агентом у реальному часі.

## 💬 Приклади команд в інтерактивному режимі

Коли активний режим чату (`Ти:`), ви можете писати звичайні речення:

* *"Знайди постачальника Молочний Гай"*
* *"Створи нового постачальника 'ЕкоПродукт' з телефоном +380501234567 та поштою info@eco.ua"*
* *"Додай до постачальника ID 1 новий товар 'Сир Голандський' (SKU: CHEESE-01, ціна: 120 грн)"*
* Для виходу з чату просто введіть: `exit`, `вихід` або `quit`.
